# kmworks

Home of the KM comic/manga reading stack — a Komga-compatible server and a native client.

- [kmreader](https://github.com/kmworks/kmreader) — a full-featured, native Komga client for iOS, macOS, and tvOS
- [kmrs](https://github.com/kmworks/kmrs) — a drop-in, API-compatible reimplementation of the [Komga](https://komga.org) server in Rust: single static binary, no JVM

kmrs pairs well with any Komga-compatible client; kmreader pairs with any Komga-compatible server, including the original [komga](https://github.com/gotson/komga).

Not affiliated with the komga project.
